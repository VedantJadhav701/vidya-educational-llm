# 🎓 Vidya 1.7B Educational LLM

Vidya is an open-source multilingual NCERT-focused educational AI assistant powered by `vedantjadhav701/edu-qwen-1.7b-merged`.

## 🏆 Multilingual Educational Benchmark (v1.0)

Vidya 1.7B achieved **93.3% overall accuracy** on the 64-item Multilingual STEM Benchmark across 8 Indian languages and 4 domains:

| Subject | Accuracy | Languages Tested |
| :--- | :---: | :--- |
| **Chemistry** | **99.4%** | English, Hindi, Marathi, Maithili, Tamil, Telugu, Bengali, Urdu |
| **Physics** | **95.6%** | English, Hindi, Marathi, Maithili, Tamil, Telugu, Bengali, Urdu |
| **Biology** | **95.6%** | English, Hindi, Marathi, Maithili, Tamil, Telugu, Bengali, Urdu |
| **Mathematics** | **82.5%** | English, Hindi, Marathi, Maithili, Tamil, Telugu, Bengali, Urdu |
